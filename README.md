# 🔗 dev-links

A sleek, responsive, and minimalist social links profile card designed to keep all my professional developer profiles and social media links in one clean place.

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen?style=for-the-badge&logo=github)](https://mo7amedxv.github.io/dev-links/)

---

## 🚀 Features

* 📱 **Mobile-First Responsive Design** – Looks stunning on any screen size, from small smartphones to large desktops.
* ✨ **Interactive Hover States** – Smooth hover animations on links to improve the user experience (UX).
* 🎨 **Modern Minimalist UI** – Clean dark-themed aesthetic with neat typography using Google Fonts.
* 🛠️ **Semantic Markup** – Built using accessible HTML5 structures for better SEO and screen readers.

---

## 🛠️ Built With

* **HTML5** – For structured, semantic markup.
* **CSS3** – Custom properties (variables), modern layouts, and transitions.
* **Google Fonts** – For clean, crisp typography.

---

## 🎯 Project Origin

This project is a solution to the **Social links profile challenge** on [Frontend Mentor](https://www.frontendmentor.io). Frontend Mentor challenges help developers improve their coding skills by building realistic projects.
